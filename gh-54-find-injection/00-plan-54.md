## Implementation plan (#54)

**1. `bdt lint` SQL rules (`lint_sql.py`)** - explicitly trust sqlglot-derived queries: `<expr>.sql(...)`, `sqlglot.*` / `exp.*` calls, `cast(LiteralString, ...)`, and calls to functions defined in the same file with `-> LiteralString`. `textwrap.dedent(x)` / `x.strip()` are unwrapped and the inner literal is checked as before. `bdt lint` behaviour otherwise unchanged (no new failures).

**2. New `bdt find-injection [PATHS...] [--diff [--base main]] [--strict]`**
- Runs on explicit files/folders, or on files changed in a git diff (branch vs base + uncommitted + untracked).
- Two severities: **error** (definite pattern, exit 1) and **review** (needs a human/AI to verify, printed with an "AI reviewer: verify..." instruction, exit 0 unless `--strict`).
- Backend (Python):
  - SQL: the injection rules already in `bdt lint` (f-string / `%` / concat / `.format`) = error; a `.execute()` argument coming from a call that is not `load_sql` / `sql.SQL` / sqlglot / `LiteralString`-typed = **review** (`sql-unverified-call`).
  - Other sinks: `eval`/`exec` on non-literals, `os.system`, `subprocess(..., shell=True)`, `pickle.loads`, `yaml.load` without a safe loader, `Markup()`/`mark_safe()`, jinja `autoescape=False`.
- Frontend (TS/JS/TSX/JSX/Vue/HTML): `dangerouslySetInnerHTML`, `innerHTML`/`outerHTML` assignment, `insertAdjacentHTML`, `document.write`, `eval`, `new Function`, string `setTimeout/setInterval`, `v-html`, `javascript:` URLs, `postMessage(..., "*")`, `<iframe>` without `sandbox` (or with `allow-scripts` + `allow-same-origin`), `srcdoc`.
- CSP: warn when a web project (frontend files or a Python web framework) has no `Content-Security-Policy` anywhere in the repo (headers in code, `<meta http-equiv>`, `staticwebapp.config.json`, nginx/web.config, ...). Also flag `unsafe-inline` / `unsafe-eval` / wildcard `script-src` (CSP weakened).
- False positives silenced with `# bdt-lint: ignore <rule>` / `// bdt-lint: ignore <rule>` (same pragma as `bdt lint`).
- Tests for each rule; README section.
